① 一行に複数の文を記述する

→セミコロン(;)を使う
name = '松田' ; print(f'僕の名前は{name}です')

②-1 一行を複数行に分けて記述する

→バックスラッシュ\を使う
n = 1 + 2 \
+ 3
print(f'答えは{n}\
改行しても足し算できていますね')

※全体のボリュームが下がるメリットがあるが、
　コードが読みにくくなるため多用は厳禁

②-2 一行を複数行に分けて記述する

→()で囲む
n = (
    1 + 2
    + 3
)

print(f'答えは{n}です。こちらの方法が一般的ですね。')

※一般的にはこちらの方法が使用される
